# Suporte — Sure Video
[Português](SUPPORT.md) | [English](docs/md/en/SUPPORT.en.md) | [Español](docs/md/es/SUPPORT.es.md)

Este documento apresenta as orientações para obter suporte, esclarecer dúvidas e relatar problemas relacionados ao **Sure Video**.

## 1. Estado do projeto

O Sure Video está em fase inicial de desenvolvimento.

O repositório é público para permitir que qualquer pessoa acompanhe sua evolução. Entretanto, o projeto ainda não possui uma estrutura formal de suporte.

## 2. Dúvidas e orientações

Para dúvidas gerais sobre o projeto:

- Consulte o `README.md` e a documentação disponível.
- Acompanhe as atualizações do repositório.
- Utilize a seção **Issues** do GitHub, caso esteja habilitada, para registrar dúvidas relacionadas ao projeto.

## 3. Relato de problemas

Caso encontre algum problema no código ou na documentação, utilize a seção **Issues** do repositório, caso esteja habilitada.

Ao registrar um problema, procure fornecer:

- Descrição clara do problema.
- Etapas necessárias para reproduzi-lo.
- Sistema operacional utilizado.
- Versão do software, quando disponível.
- Mensagens de erro ou evidências relevantes.

## 4. Segurança

Problemas relacionados à segurança não devem ser publicados em Issues públicas.

Consulte o arquivo `SECURITY.md` para obter orientações sobre o relato privado de vulnerabilidades.

## 5. Contribuições

O acompanhamento público não significa autorização para contribuições externas.

Durante esta fase, Pull Requests e alterações externas não estão autorizados sem aprovação prévia do titular do projeto.

Consulte `CONTRIBUTING.md` para conhecer as condições atuais.

## 6. Tempo de resposta

Como o projeto é mantido individualmente e ainda está em desenvolvimento, não existe prazo garantido para respostas ou resolução de problemas.

## 7. Atualizações

Este documento poderá ser atualizado conforme o projeto evoluir e uma estrutura formal de suporte for estabelecida.
