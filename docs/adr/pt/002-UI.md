# ADR-002: Escolha do framework gráfico

- **Status:** Aceito
- **Data:** 24/11/2026
- **Decisão:** Utilizar Fyne

## 1. Contexto

O Sure Video é uma aplicação Desktop destinada à gestão de equipes de filmagem, desenvolvida em Go e com funcionamento offline.

É necessário escolher um framework gráfico que permita construir uma interface desktop multiplataforma, mantendo a integração com a linguagem principal do projeto.

A solução deve permitir desenvolver telas, formulários, componentes visuais e mecanismos de navegação sem depender de tecnologias Web.

## 2. Alternativas consideradas

- **Fyne:** framework gráfico escrito em Go, com suporte ao desenvolvimento de aplicações multiplataforma.
- **Wails:** framework para aplicações Desktop que utiliza tecnologias Web no frontend e Go no backend.
- **Gio:** toolkit gráfico para desenvolvimento de interfaces em Go.
- **Qt:** framework multiplataforma consolidado, com integração por meio de bindings para Go.

## 3. Decisão

Foi escolhido o **Fyne** como framework gráfico para o desenvolvimento da interface do Sure Video.

A escolha considera os seguintes fatores:

- Integração direta com Go.
- Desenvolvimento de interfaces utilizando a própria linguagem Go.
- Suporte a Linux e Windows.
- Componentes gráficos para construção de formulários e telas.
- Possibilidade de desenvolver aplicações Desktop sem utilizar tecnologias Web.
- Ecossistema de desenvolvimento adequado ao escopo do projeto.

## 4. Consequências

### Positivas

- Utilização de uma única linguagem principal no desenvolvimento.
- Menor complexidade na integração entre frontend e backend.
- Desenvolvimento de interfaces sem HTML, CSS ou JavaScript.
- Possibilidade de distribuição para diferentes sistemas operacionais.
- Integração com bibliotecas e recursos
