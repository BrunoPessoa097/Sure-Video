# ADR-002: Graphical Framework Selection

- **Status:** Accepted
- **Date:** 24/11/2026
- **Decision:** Use Fyne

## 1. Context

Sure Video is a desktop application for managing film crews, developed in Go and designed to work offline.

A graphical framework must be selected that allows building a cross-platform desktop interface while maintaining integration with the project's primary language.

The solution must support the development of screens, forms, visual components, and navigation mechanisms without relying on Web technologies.

## 2. Alternatives considered

- **Fyne:** a graphical framework written in Go, with support for cross-platform application development.
- **Wails:** a desktop application framework that uses Web technologies in the frontend and Go in the backend.
- **Gio:** a graphical toolkit for developing interfaces in Go.
- **Qt:** an established cross-platform framework, integrated through Go bindings.

## 3. Decision

**Fyne** was chosen as the graphical framework for developing the Sure Video interface.

The choice is based on the following factors:

- Direct integration with Go.
- Interface development using Go itself.
- Support for Linux and Windows.
- Graphical components for building forms and screens.
- Ability to develop desktop applications without using Web technologies.
- A development ecosystem suited to the project's scope.

## 4. Consequences

### Positive

- Use of a single primary language in development.
- Less complexity in frontend and backend integration.
- Interface development without HTML, CSS, or JavaScript.
- Ability to distribute to different operating systems.
- Integration with libraries and resources
