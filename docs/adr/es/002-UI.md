# ADR-002: Elección del framework gráfico

- **Estado:** Aceptado
- **Fecha:** 24/11/2026
- **Decisión:** Utilizar Fyne

## 1. Contexto

Sure Video es una aplicación de escritorio destinada a la gestión de equipos de filmación, desarrollada en Go y diseñada para funcionar sin conexión.

Es necesario elegir un framework gráfico que permita construir una interfaz de escritorio multiplataforma y, al mismo tiempo, mantener la integración con el lenguaje principal del proyecto.

La solución debe permitir desarrollar pantallas, formularios, componentes visuales y mecanismos de navegación sin depender de tecnologías web.

## 2. Alternativas consideradas

- **Fyne:** framework gráfico escrito en Go, compatible con el desarrollo de aplicaciones multiplataforma.
- **Wails:** framework para aplicaciones de escritorio que utiliza tecnologías web en el frontend y Go en el backend.
- **Gio:** toolkit gráfico para desarrollar interfaces en Go.
- **Qt:** framework multiplataforma consolidado, integrado mediante bindings para Go.

## 3. Decisión

Se eligió **Fyne** como framework gráfico para desarrollar la interfaz de Sure Video.

La elección tiene en cuenta los siguientes factores:

- Integración directa con Go.
- Desarrollo de interfaces utilizando el propio lenguaje Go.
- Compatibilidad con Linux y Windows.
- Componentes gráficos para construir formularios y pantallas.
- Posibilidad de desarrollar aplicaciones de escritorio sin utilizar tecnologías web.
- Ecosistema de desarrollo adecuado al alcance del proyecto.

## 4. Consecuencias

### Positivas

- Uso de un único lenguaje principal durante el desarrollo.
- Menor complejidad en la integración entre frontend y backend.
- Desarrollo de interfaces sin HTML, CSS ni JavaScript.
- Posibilidad de distribuir la aplicación para distintos sistemas operativos.
- Integración con bibliotecas y recursos
