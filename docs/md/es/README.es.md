# Sure de Vídeo
[Português](../../../README.md) | [English](../en/README.en.md) | [Español](README.es.md)

**Sistema de gestión de equipos de filmación.**

Sure de Vídeo es un proyecto de software libre que se encuentra actualmente en sus etapas iniciales de planificación y desarrollo. Su objetivo es facilitar la organización y gestión de equipos de producción audiovisual.

El proyecto busca ofrecer una aplicación de escritorio sencilla y organizada para administrar personas, funciones, días de trabajo y escalas de los equipos de filmación.

## Objetivo

Desarrollar una herramienta que facilite la organización de los equipos de producción audiovisual, centralizando la información y simplificando la gestión de las actividades.

## Funcionalidades planificadas

El proyecto se encuentra en su etapa inicial de planificación. Las siguientes funcionalidades están previstas:

- [ ] Registro y gestión de personas.
- [ ] Registro y gestión de funciones.
- [ ] Gestión de días de trabajo.
- [ ] Creación y gestión de escalas de trabajo.
- [ ] Panel de control para visualizar la información.
- [ ] Navegación entre los módulos de la aplicación.

Las funcionalidades se implementarán gradualmente durante el desarrollo.

## Plataformas

La aplicación se desarrollará como software de escritorio, con soporte inicial para:

- Linux
- Windows

El funcionamiento será local y sin conexión a Internet, sin depender de servicios externos para las operaciones principales.
