# Soporte — Sure Video
[Português](../../../SUPPORT.md) | [English](../en/SUPPORT.en.md) | [Español](SUPPORT.es.md)

Este documento presenta las instrucciones para obtener soporte, resolver dudas e informar problemas relacionados con **Sure Video**.

## 1. Estado del proyecto

Sure Video se encuentra en una etapa inicial de desarrollo.

El repositorio es público para que cualquier persona pueda seguir su evolución. Sin embargo, el proyecto todavía no cuenta con una estructura formal de soporte.

## 2. Dudas y orientación

Para consultas generales sobre el proyecto:

- Consulte el `README.md` y la documentación disponible.
- Siga las actualizaciones del repositorio.
- Utilice la sección **Issues** de GitHub, si está habilitada, para registrar preguntas relacionadas con el proyecto.

## 3. Informe de problemas

Si encuentra algún problema en el código o en la documentación, utilice la sección **Issues** del repositorio, si está habilitada.

Al informar un problema, procure proporcionar:

- Una descripción clara del problema.
- Los pasos necesarios para reproducirlo.
- El sistema operativo utilizado.
- La versión del software, cuando esté disponible.
- Mensajes de error o evidencias relevantes.

## 4. Seguridad

Los problemas relacionados con la seguridad no deben publicarse en Issues públicas.

Consulte el archivo `SECURITY.md` para obtener instrucciones sobre cómo informar vulnerabilidades de forma privada.

## 5. Contribuciones

El acceso público al repositorio no implica autorización para realizar contribuciones externas.

Durante esta etapa, los Pull Requests y los cambios externos no están autorizados sin la aprobación previa del titular del proyecto.

Consulte `CONTRIBUTING.md` para conocer las condiciones actuales.

## 6. Tiempo de respuesta

Como el proyecto es mantenido por una sola persona y todavía está en desarrollo, no se garantiza ningún plazo de respuesta o resolución de problemas.

## 7. Actualizaciones

Este documento podrá actualizarse a medida que el proyecto evolucione y se establezca una estructura formal de soporte.
