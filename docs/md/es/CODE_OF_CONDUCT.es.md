# Código de Conducta
[Português](../../../CODE_OF_CONDUCT.md) | [English](../en/CODE_OF_CONDUCT.en.md) | [Español](CODE_OF_CONDUCT.es.md)
## Nuestro compromiso

Sure Video tiene como objetivo construir un entorno de desarrollo colaborativo, respetuoso e inclusivo.

Esperamos que todos los participantes contribuyan de manera constructiva, independientemente de su experiencia profesional, conocimientos técnicos, origen o características personales.

## Comportamientos esperados

Se esperan las siguientes actitudes:

- Respetar opiniones, experiencias y diferentes puntos de vista.
- Mantener una comunicación cordial y profesional.
- Aceptar críticas constructivas y ofrecer comentarios de manera respetuosa.
- Priorizar discusiones técnicas fundamentadas.
- Colaborar para mantener un entorno saludable y productivo.
- Respetar el trabajo y las contribuciones de otras personas.

## Comportamientos inaceptables

No se tolerarán:

- Acoso, discriminación o intimidación.
- Ataques personales o comentarios ofensivos.
- Lenguaje discriminatorio o prejuicioso.
- Publicación de información personal sin autorización.
- Comportamientos que perjudiquen intencionalmente el entorno de colaboración.
- Cualquier forma de amenaza o persecución.

## Directrices de comunicación

Las discusiones relacionadas con el proyecto deben mantenerse centradas en sus objetivos.

Al participar en Issues, Pull Requests u otros canales de comunicación:

- Presentar información clara y objetiva.
- Evitar discusiones personales.
- Fundamentar las sugerencias y críticas siempre que sea posible.
- Respetar las decisiones técnicas y los procesos de revisión del proyecto.

## Responsabilidades

Los responsables del proyecto se comprometen a:

- Mantener un entorno de colaboración respetuoso.
- Evaluar los informes de incumplimiento de este código.
- Tomar medidas proporcionales a la gravedad de cada situación.
- Proteger la privacidad de las personas involucradas siempre que sea posible.

## Aplicación del código de conducta

Las infracciones podrán dar lugar a:

1. Orientación o advertencia.
2. Restricción temporal de participación.
3. Eliminación de contribuciones inapropiadas.
4. Suspensión o finalización de la participación en el proyecto.

Las medidas se determinarán considerando la gravedad y la recurrencia del comportamiento.

## Comunicación de infracciones

Los problemas relacionados con el incumplimiento de este código deben comunicarse directamente al responsable del proyecto mediante un canal privado de comunicación.

Evita exponer públicamente información personal o detalles sensibles relacionados con el informe.

## Alcance

Este código se aplica a las interacciones relacionadas con Sure Video, incluyendo:

- El repositorio del proyecto.
- Issues y Pull Requests.
- Debates técnicos.
- Canales oficiales de comunicación.
- Eventos o actividades relacionados con el proyecto.

## Consideraciones finales

Este código podrá actualizarse a medida que Sure Video y su comunidad evolucionen.

Al participar en el proyecto, se espera que todos respeten estas directrices.
