# Support — Sure Video
[Português](../../../SUPPORT.md) | [English](SUPPORT.en.md) | [Español](../es/SUPPORT.es.md)

This document provides guidelines for obtaining support, asking questions, and reporting issues related to **Sure Video**.

## 1. Project Status

Sure Video is in its early development stage.

The repository is public so anyone can follow its progress. However, the project does not yet have a formal support structure.

## 2. Questions and Guidance

For general questions about the project:

- Check the `README.md` and available documentation.
- Follow repository updates.
- Use the GitHub **Issues** section, if enabled, to submit questions related to the project.

## 3. Reporting Issues

If you find a problem in the code or documentation, use the repository's **Issues** section, if enabled.

When reporting an issue, try to provide:

- A clear description of the problem.
- Steps required to reproduce it.
- The operating system being used.
- The software version, when available.
- Relevant error messages or evidence.

## 4. Security

Security-related issues must not be reported through public Issues.

Refer to `SECURITY.md` for instructions on privately reporting vulnerabilities.

## 5. Contributions

Public access to the repository does not imply authorization for external contributions.

During this stage, Pull Requests and external changes are not authorized without prior approval from the project owner.

Refer to `CONTRIBUTING.md` for the current conditions.

## 6. Response Time

Since the project is maintained by an individual and is still under development, no response or issue resolution timeframe is guaranteed.

## 7. Updates

This document may be updated as the project evolves and a formal support structure is established.
