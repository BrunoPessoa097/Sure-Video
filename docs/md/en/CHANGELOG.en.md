## Versioning

The project intends to use Semantic Versioning:

`MAJOR.MINOR.PATCH`

- **MAJOR:** incompatible changes with previous versions.
- **MINOR:** new features that remain backward compatible.
- **PATCH:** backward-compatible bug fixes.

Versions will be identified using Git tags.
