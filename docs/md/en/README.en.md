# Sure de Vídeo
[Português](../../../README.md) | [English](README.en.md) | [Español](../es/README.es.md)

**Film Crew Management System.**

Sure de Vídeo is an software project currently in its planning and early development stages. Its goal is to help organize and manage film production crews.

The project aims to provide a simple and organized desktop application for managing people, job roles, working days, and crew schedules.

## Objective

To develop a tool that improves the organization of audiovisual production teams by centralizing information and simplifying activity management.

## Planned Features

The project is currently in its initial planning stage. The following features are planned:

- [ ] People registration and management.
- [ ] Job roles registration and management.
- [ ] Working days management.
- [ ] Crew schedule creation and management.
- [ ] Dashboard for information overview.
- [ ] Navigation between application modules.

Features will be implemented gradually throughout development.

## Platforms

The application will be developed as desktop software, initially targeting:

- Linux
- Windows

The application is intended to operate locally and offline, without depending on external services for its core operations.
