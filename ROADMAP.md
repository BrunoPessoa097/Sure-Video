# Roadmap — Sure Video
[Português](ROADMAP.md) | [English](docs/md/en/ROADMAP.en.md) | [Español](docs/md/es/ROADMAP.es.md)

Este documento apresenta o planejamento de desenvolvimento do **Sure Video**, incluindo suas etapas, objetivos e funcionalidades previstas.

O roadmap poderá ser atualizado conforme as necessidades do projeto e as decisões tomadas durante o desenvolvimento.

## Estado atual

<badge color="warning">Em planejamento</badge>

O projeto está em fase de planejamento e organização. Nenhuma funcionalidade foi implementada até o momento.

## Observações

- As etapas representam o planejamento atual e podem sofrer alterações.
- A conclusão de uma etapa não significa necessariamente que todas as funcionalidades previstas estejam finalizadas.
- Novas funcionalidades poderão ser adicionadas conforme a evolução do projeto.
- O projeto prioriza funcionamento local e operação offline.

## Versionamento

As versões serão organizadas conforme a estratégia de versionamento adotada pelo projeto.

A primeira versão estável planejada é a `1.0.0`.
