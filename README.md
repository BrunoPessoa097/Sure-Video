# Sure de Vídeo
[Português](README.md) | [English](docs/md/en/README.en.md) | [Español](docs/md/es/README.es.md)

**Sistema de gerenciamento de equipes de filmagem.**

O Sure de Vídeo é um projeto de software em desenvolvimento, criado com o objetivo de auxiliar na organização e no gerenciamento de equipes de produção audiovisual.

A proposta é oferecer uma aplicação desktop simples e organizada para administrar pessoas, funções, dias de trabalho e escalas de equipes de filmagem.

## Objetivo

Desenvolver uma ferramenta que facilite a organização das equipes de produção audiovisual, centralizando informações e simplificando o gerenciamento das atividades.

## Funcionalidades planejadas

O projeto está em fase inicial de planejamento. As funcionalidades previstas incluem:

- [ ] Cadastro e gerenciamento de pessoas.
- [ ] Cadastro e gerenciamento de funções.
- [ ] Gerenciamento de dias de trabalho.
- [ ] Criação e gerenciamento de escalas.
- [ ] Dashboard para visualização das informações.
- [ ] Navegação entre os módulos da aplicação.

As funcionalidades serão implementadas gradualmente durante o desenvolvimento.

## Plataforma

A aplicação será desenvolvida para desktop, com foco inicial em:

- Linux
- Windows

O funcionamento será local e offline, sem dependência de serviços externos para as operações principais.
